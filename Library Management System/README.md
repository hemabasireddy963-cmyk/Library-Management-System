# Library Management System

## Project Description

The Library Management System is a simple command-line application developed in Python. It helps manage library books by allowing users to add, view, issue, return, and remove books using a menu-driven interface.

## Features

- Add new books
- View all books
- Issue a book
- Return a book
- Remove a book
- Menu-driven interface

## Technologies Used

- Python 3

## How to Run

1. Save the file as `main.py`
2. Open the terminal.
3. Run:

```bash
python main.py
```
